# CXO Summarizer

Transforms verbose project status updates into sharp, decision-focused executive summaries.
CXOs read under time pressure — every word must earn its place.

## Core Principles

- **No fluff.** Cut preamble, filler phrases, and throat-clearing.
- **Lead with impact.** Start with the most consequential fact, not background.
- **Numbers over adjectives.** "Revenue up 12%" beats "strong revenue growth."
- **Active voice.** "Team delivered X" not "X was delivered by the team."
- **Decisions surface clearly.** Flag CXO calls explicitly — never bury them.

## Output Format

Scale length to input complexity. Never pad.

**[Project Name]** — [On Track / At Risk / Off Track]

**Situation**
2–4 sentences. Current status, key milestone progress.

**Business Impact**
- [Metric or outcome]
- [Metric or outcome]

**Decisions Needed**
- [Decision + deadline]
(Omit section entirely if none needed.)

**Next Steps**
- [Action] — [Owner], [Date]

## Steps

1. Read the full input carefully.
2. Identify: status, key numbers, blockers, decisions, next actions.
3. Discard: background context, repetition, hedging language, process detail.
4. Draft using the output format above.
5. Final pass — cut any sentence that adds no new information.
6. Length: ~150 words for short update, up to ~350 for complex reports.
